# LearnerSim v6：论文实验待做计划

> 正式评价指标固定为：BAA、Balanced Accuracy、F1、ADCDE。所有主实验使用锁定代码、固定 cohort、同一 leakage-safe DKT/NCDM checkpoint，并保存逐步过程数据。

## P0：正式主表与强基线

- [ ] 在 MOOCradar、XES3G5M、FoundationAssist 三个数据集各完成 500 名学习者、每人 10 个 target step 的正式主实验。
- [ ] 每个数据集报告 Full、四组消融及 DKT/NCDM 的 BAA、Balanced Accuracy、F1、ADCDE。
- [ ] 适配并比较 Agent4Edu、DAISim、KES 等强学习者模拟基线；统一 cohort、历史信息边界、target steps 和评价脚本。无法严格复现时，记录不可比原因与实际可用配置。

## P1：ADCDE 分层诊断

- [ ] 对能力高/低 × 题目难/易的固定 2×2 分层，报告真实正确率、模拟正确率与绝对差。
- [ ] 解释 ADCDE 的主要误差来源，特别检查低能力学习者上的系统性偏高或偏低。

## P2：反事实验证与过程真实性盲评

- [ ] 在独立固定 cohort 上做受控反事实验证：替换/移除关键历史证据，检验状态、证据和最终作答是否按预注册方向变化；仅称为过程敏感性验证，不作真实学生因果宣称。
- [ ] 组织双人盲评：隐藏方法名，评估过程记录的证据贴合度、状态一致性、理由充分性与不确定性校准；报告一致性及分歧处理规则。

## P3：成本、吞吐与时长

- [ ] 报告每 step token、端到端时延、失败率、定点修复率、40 路并发吞吐与各数据集总时长。
- [ ] 明确模型版本、temperature、thinking 设置、API 日期和实现指纹。

## P4：证据干预一致性实验

- [ ] 对同一历史长度构造原始证据、证据替换、随机证据与空证据条件；比较最终预测、状态和引用证据的方向性与稳定性。
- [ ] 验证模型确实依赖与当前题目相关的历史证据，而非只依赖输出模板或全局正确率。

## P5：下游效用实验

- [ ] 使用模拟轨迹训练或增强一个下游 KT/推荐模型，并在真实 held-out 学习者上评测。
- [ ] 比较真实数据、真实+Full 模拟数据、真实+最佳基线模拟数据，报告统一的预测指标和数据量设置。

## 不采用的做法

- [ ] 不以更低 ADCDE 为唯一目标进行事后标签翻转或阈值校准。
- [ ] 不把答案键可见性称作 target-label leakage：LLM 看不到真实学生 target response；持续审计 `LearnerCorrect` 与最终 `StudentAnswer` 一致性即可。
- [ ] 不把 prompt 反事实干预表述为真实学生因果识别。
- [ ] 不混合不同代码、checkpoint、cohort 或有效学习者集合的结果。
