# MoocRadar Medium70 Balanced-state Full

Snapshot date: 2026-07-25.

This note fixes the current MoocRadar medium-difficulty result for the
balanced-state Full learner simulator.

## Protocol

- Dataset: MoocRadar
- Cohort: `experiments/cohorts/moocradar_90_10_10x10_medium70.json`
- Target correct rate: 70/100
- Protocol: 90 observed history interactions, then 10 teacher-forcing target
  simulations for each of 10 learners
- DKT state file:
  `outputs/dkt/moocradar_full_e50_h100/moocradar_90_10_10x10_medium70_proficiency.json`
- LLM config: `configs/llm.example.json`
- Active model at run time: `deepseek-v4-flash`

## Current Method

The current Full simulator combines:

1. learner historical evidence encoding;
2. cognitive profile construction;
3. ability profile construction without IRT;
4. DKT mastery as balanced state evidence rather than an answer label;
5. four-tier learner response generation;
6. multi-task diagnostics for analysis.

The response prompt does not expose `p_correct`, reference labels,
`predicted_response`, or `kt_decision_anchor`. The final correctness decision is
still generated by the LLM and scored externally.

## Interpretation

The current balanced-state Full version is the strongest result on this
medium-correct-rate MoocRadar cohort among the LLM simulator variants currently
recorded here. It does not beat the DKT predictor on ACC or F1, but it has
better Balanced Accuracy, Specificity, MCC, and LDE.

The key difference is negative-sample recognition. DKT predicts most targets as
correct and only identifies 6 true negatives. The current simulator identifies
19 true negatives while keeping 50 true positives, which makes it more suitable
for learner simulation than pure correctness prediction on this cohort.
